# Baekji

BaekJi (백지) is a 'blank paper' in Korean.
Simple and minimal writing tool for any platform, including desktop and mobile.

## 소개

백지는 최소한의 구성을 가진 집필용 도구입니다.
문서 양식이 거의 필요 없는 글쓰기를 위한 환경을 제공합니다.

### 목표 기능

- 프로젝트 - 시트 구조 + 태그 필터로 글 관리
- 라이브 프리뷰가 있는 마크다운 편집기
- 손쉬운 글 내보내기 및 공유
- 설치 불필요, 데스크탑이든 모바일이든 브라우저만 있다면 사용 가능
- PWA 지원으로 오프라인 앱처럼 사용 가능

### 목표가 아닌 기능

- 복잡한 양식이 필요한 글쓰기 및 일반적인 마크다운 전체 지원
- 협업, 미디어 관리 등
- 다이어그램, 표 등 글쓰기 외 기능
- 폴더/그룹 트리 구조

## 사용법

### 글 관리

백지에서는 모든 글을 **프로젝트 - 시트** 구조로 관리합니다.

- **프로젝트**: 최상위 단위로, 여러 시트를 포함합니다.
- **시트**: 하나의 글 조각입니다. 마크다운으로 작성하며, 마크다운 텍스트 형식으로 저장됩니다.

모든 데이터는 브라우저에 자동으로 저장되며, 브라우저에서 데이터 삭제를 하지 않는 이상 영구적으로 보존됩니다.

### 사이드바

화면 좌측 상단의 버튼(`Ctrl+L` / `Cmd+L`)으로 사이드바를 열고 닫을 수 있습니다.

사이드바 상단에서 **프로젝트 목록**과 **현재 프로젝트의 시트 목록** 사이를 전환할 수 있습니다.

### 프로젝트

프로젝트 목록 화면에서 새 프로젝트를 만들거나 기존 백업 파일(`.json`)을 불러올 수 있습니다.

프로젝트는 서로 독립적으로 관리되며 영향을 주지 않습니다.

**백업**: 프로젝트의 모든 데이터를 하나의 `.json` 파일로 내보낼 수 있습니다. 여러 기기에서 사용하려면 이 파일을 클라우드 저장소(또는 Dropbox)에 올려 두고 각 기기에서 불러오는 방식으로 활용할 수 있습니다.

### 글 정리 방법

백지는 의도적으로 평탄한 구조입니다. 폴더나 그룹 트리는 없습니다. 대신 다음과 같은 방식을 추천합니다.

- **시트를 대략적인 순서로 나열** — 드래그로 의미 있는 순서를 만들어 두세요. 시트 목록은 긴 두루마리라고 생각하면 됩니다. 위치 자체가 맥락이 됩니다.
- **태그로 가로로 묶기** — 하나의 시트에 태그를 여러 개 붙일 수 있으므로, 복사 없이 여러 "분류"에 동시에 속할 수 있습니다.
- **콜론(`:`)으로 태그에 네임스페이스 붙이기** — 규칙은 아니지만, `작품:A`, `작품:B`처럼 공통 접두사를 붙여두면 `작품:*`로 한 번에 검색할 수 있어 편리합니다.

**예시**: 소설 작업을 한다면 작품명과 내용 종류를 함께 태그로 붙일 수 있습니다.

| 시트            | 태그             |
| --------------- | ---------------- |
| 작품A 1화 초안  | `작품:A`, `본문` |
| 작품A 설정 메모 | `작품:A`, `설정` |
| 작품B 1화 초안  | `작품:B`, `본문` |
| 아이디어 노트   | `아이디어`       |

이렇게 해두면 `작품:* & 본문`으로 모든 작품의 본문 초안을 한 번에 볼 수 있고, `작품:A`로 작품A 관련 시트만, `!본문`으로 본문이 아닌 시트만 볼 수 있습니다.

### 시트 목록

현재 프로젝트의 모든 시트를 스크롤 가능한 선형 목록으로 표시합니다.

- 시트를 **드래그**하여 순서를 바꿀 수 있습니다.
- 상단의 **태그 필터**를 이용해 태그로 시트를 걸러볼 수 있습니다. 지정한 태그를 모두 가진 시트만 표시됩니다.
- 여러 시트를 **선택**하여 일괄 작업을 할 수 있습니다. `Shift+클릭`으로 범위 선택, `Ctrl/Cmd+클릭`으로 개별 선택이 가능합니다.
  - 선택된 시트를 일괄 삭제할 수 있습니다.
  - 정확히 **두 시트**를 선택하면 **비교(Compare)** 화면을 열어 차이를 확인하고 병합할 수 있습니다.
- 삭제된 시트는 목록 하단의 **휴지통** 섹션에 보관됩니다. 복원하거나 영구 삭제할 수 있습니다.

**컨텍스트 메뉴** (시트 항목을 우클릭하거나 `...` 버튼 사용):

- 태그 편집
- 분석 보기
- 내보내기
- 위/아래에 새 시트 추가
- 아래 시트와 병합
- 삭제

### 태그

각 시트에 태그를 하나 이상 지정할 수 있습니다. 태그는 프로젝트 내 시트를 분류하고 필터링하는 데 사용됩니다.

- 시트 항목의 컨텍스트 메뉴에서 **태그**를 선택해 태그를 추가하거나 수정할 수 있습니다.
- 태그 필터 입력란에 태그 이름을 입력하면 해당 태그를 가진 시트만 표시됩니다.
- 태그 색상은 **프로젝트** 개요 페이지에서 커스터마이징할 수 있습니다.

#### 태그 쿼리 문법

필터 입력란과 검색에서 아래의 쿼리 문법을 사용할 수 있습니다.

| 문법       | 의미                                  | 예시                      |
| ---------- | ------------------------------------- | ------------------------- |
| `태그`     | 해당 태그가 있는 시트                 | `본문`                    |
| `접두사:*` | `접두사:`로 시작하는 태그가 있는 시트 | `작품:*`                  |
| `*`        | 태그가 하나라도 있는 시트             | `*`                       |
| `A & B`    | AND — 두 조건 모두 만족               | `작품:A & 본문`           |
| `A \| B`   | OR — 둘 중 하나 만족                  | `초안 \| 수정`            |
| `!A`       | NOT — 조건을 만족하지 않음            | `!삭제예정`               |
| `(…)`      | 그룹                                  | `작품:* & (초안 \| 수정)` |

연산자 주변의 공백은 무시됩니다. 빈 쿼리는 모든 시트에 매칭됩니다.

**팁**:

- 콜론(`:`)은 태그 이름의 일반 문자입니다. `작품:A`는 하나의 태그입니다. 네임스페이스처럼 쓰는 것은 관례이며, `작품:*` 같은 글로브 검색을 유용하게 만들어 줍니다.
- `!작품:* & (초안 | 수정)` — 작품 태그는 없지만 초안이거나 수정인 시트.
- 필터가 활성화된 상태에서 새 시트를 만들면 필터에 맞는 태그가 자동으로 채워집니다.

### 시트

시트는 다른 프로그램의 '파일'에 해당합니다. 시트에는 별도의 이름이 없으며, 내용의 첫 줄을 발췌하여 이름 대신 화면에 표시됩니다.

편집기는 **라이브 프리뷰가 있는 마크다운 편집기**입니다. 서식 버튼(툴바)은 없으며, 마크다운을 직접 입력하면 에디터가 실시간으로 렌더링합니다.

- `# ` → 제목 1, `## ` → 제목 2, `### ` → 제목 3
- `- ` 또는 `* ` → 불릿 목록, `1. ` → 번호 목록
- `**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``
- `> ` → 인용, ` ``` ` → 코드 블록

편집기 우측 상단에는 글자 수가 표시됩니다. **`...`** 버튼을 누르면 다음 메뉴가 열립니다.

- **찾기 및 바꾸기** (`Ctrl+F` / `Cmd+F`)
- **복사** — 전체 내용을 클립보드에 복사
- **내보내기** — 이 시트를 내보내기
- **분석** — 이 시트의 분석 화면 열기
- **분할** — 커서 위치에서 두 시트로 나누기

파일을 열면 마지막으로 편집하던 위치(커서)가 복원됩니다.

**자동 저장**: 변경 사항은 자동으로 저장됩니다. 수동으로 저장하려면 `Ctrl+S` (macOS: `Cmd+S`)를 누릅니다.

### 비교 및 병합

두 시트를 비교하고 병합하려면:

1. 시트 목록에서 선택 모드로 전환하여 정확히 두 시트를 선택합니다.
2. 나타나는 **비교(Compare)** 버튼을 누릅니다.
3. 비교 화면에서 달라진 각 블록에 **유지(Keep)** 와 **건너뜀(Skip)** 버튼이 표시됩니다.
   - **유지** (`A` / `B` 표시) — 이 블록을 결과에 포함
   - **건너뜀** — 이 블록을 제외
4. 모든 블록을 결정한 뒤 체크 버튼을 누르면 병합이 완료됩니다. 결과는 첫 번째 시트에 저장되고, 두 번째 시트는 휴지통으로 이동합니다.

### 내보내기

내보내기 페이지에서 여러 시트를 하나의 문서로 합쳐 내보낼 수 있습니다. 지원 형식:

- **Markdown** — 시트 사이의 구분자를 직접 설정할 수 있는 원본 마크다운
- **Plain Text** — 마크다운 기호를 제거한 순수 텍스트
- **HTML** — `DOCTYPE`과 `charset`이 포함된 완전한 HTML 문서

내보내기 전에 태그 필터로 포함할 시트를 지정하거나, 시트를 직접 선택한 뒤 내보내기를 열어 대상을 좁힐 수 있습니다.

### 분석

분석 페이지에서는 각 시트(및 전체 합계)에 대한 통계를 확인할 수 있습니다.

- 바이트 크기
- 전체 글자 수
- 공백 제외 글자 수
- 특수문자 제외 글자 수
- 단어 수
- 예상 읽기 시간 (200 WPM 기준)

### 설정

설정에서 다음 항목을 조정할 수 있습니다.

- **테마**: 라이트/다크 각각 기본(Default), 웜(Warm), 쿨(Cool) 중 선택
- **타이포그래피**: 본문 글꼴(산세리프/세리프), 산세리프·세리프·고정폭 각각의 폰트 선택(Noto 폰트 포함), 에디터·미리보기 글자 크기, 폰트 굵기, 줄 간격, 첫 줄 들여쓰기, 문단 간격, 텍스트 정렬
  - Noto 폰트를 사용하면 한글을 포함한 다국어 글꼴을 지원하지만 최대 30MB 다운로드가 필요합니다.
- **편집기**: 타이프라이터 모드(커서를 화면 중앙에 고정), 포커스 모드(현재 줄 외 나머지를 흐리게 표시)

### PWA (앱으로 설치)

백지는 PWA(Progressive Web App)를 지원합니다. 브라우저에서 '홈 화면에 추가' 또는 '앱 설치' 옵션을 선택하면 오프라인에서도 사용할 수 있는 독립 앱처럼 실행됩니다.
